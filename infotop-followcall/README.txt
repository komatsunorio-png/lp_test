フォローコールサービス(FCS) LP  README
==================================================

■ 公開前に差し替え・確認が必要な箇所
--------------------------------------------------
1. (対応済み)プライバシーポリシーのリンク先は https://first-penguin.co.jp/company/privacy に設定済みです。
2. 資料ZIPのURL(index.html「資料ダウンロード」のボタン)
   → 現在は旧ページと同じ https://www.infotop.jp/html/followcall/231201_followcall_fcs.zip を参照しています。
     資料を更新した場合は、ファイル名・URLを差し替えてください。
3. canonical / OGP の URL(index.html の <head>)
   → 本番の設置場所 https://www.infotop.jp/html/followcall/ を想定しています。設置場所が変わる場合は
     canonical、og:url、og:image、twitter:image の4か所を合わせて変更してください。
4. 計測タグ
   → 旧ページの Google アナリティクス(UA / ga.js)はすでに計測が止まっているため外しています。
     GA4 などを入れる場合は </head> の直前に追加してください。
5. 画像の解像度(差し替え推奨)
   → images/fv_operator.png は AI 生成画像の切り出しのため 324×513px です(高精細な画面ではやや甘く見えます)。
   → images/voice_logo_*.png は旧ページの画像から切り出したため、少しぼやけています。正式なロゴデータがあれば差し替えてください。

■ フォルダ構成
--------------------------------------------------

CREDITS.txt       … 画像の出典

■ 文言の変更
--------------------------------------------------
・文言はすべて index.html にテキストで入っています(画像化している文字はありません)。
  エディタで該当の文章を検索して直接書き換えてください。
・マーカー(黄色の下線)は <span class="marker"> / <strong class="marker"> で囲った部分に付きます。
・PCだけ・SPだけの改行は <br class="u-pc"> / <br class="u-sp"> で指定しています。

■ ケース(CASE 01〜03)の追加・削除・並べ替え
--------------------------------------------------
・「▼▼▼ ケース N ここから」〜「▲▲▲ ここまで」の範囲が1件分です。
・追加:1件分をコピーして貼り付け、id(case1 など)と aria-labelledby / 見出しの id を重複しない名前に変えます。
  色は article の class(case-card--blue / --orange / --green)で切り替えます。
・削除:1件分をまるごと消します。ページ上部の「お悩み別ボタン」(case-nav)と「お悩み提起」の該当項目も合わせて消してください。
・並べ替え:1件分ずつ切り取って入れ替えます。

■ 導入事例の追加・削除・並べ替え
--------------------------------------------------
・「▼▼▼ 導入事例 N ここから」〜「▲▲▲ ここまで」の範囲が1件分です。
・構成は固定:ロゴ → 商材名 → 会社名 → 成果の数値 → コメント。
・成果の数値は <dl class="voice-card__stats"> の中の <div> 1つが1項目です。
  強調したい項目には class="is-strong" を付けます。項目が1つだけの場合は voice-card__stats--single を付けます。
・数字は <span data-count="35">35</span> のように、data-count と表示の数字の両方を同じ値にしてください
  (スクロールで0からカウントアップします)。

■ 画像の差し替え
--------------------------------------------------
・images/ の同じファイル名・同じ縦横比の画像で上書きすれば差し替わります。
  logo.png(ロゴ、背景透過) / fv_operator.png(FVの人物、背景透過・腰から上)
  persona_01〜03.jpg(お悩みの人物、正方形) / talk_operator.png(トーク例のアイコン、正方形)
  voice_logo_carlot.png・voice_logo_thousandfaith.png(導入事例のロゴ、正方形)
  ogp.jpg(SNS共有用、1200×630)
・ブラウザのキャッシュで古い表示が残る場合は、index.html の style.css?v=1 / main.js?v=1 の数字を上げてください。

■ 動きについて
--------------------------------------------------
・ボタン:PCはマウスオーバー、SPはタップで押し下がります。
・お悩み別ボタンなどのページ内リンクは、スムーズにスクロールします。
・各ブロックはスクロールで下からふわっと表示され、成果の数字はカウントアップします。
・OSで「視差効果を減らす」などの設定をしている閲覧者には、アニメーションを止めて表示します。
・SPでは、FVを過ぎると画面下に「資料ダウンロード/電話する」の追従ボタンが出ます(お問い合わせ欄では隠れます)。
