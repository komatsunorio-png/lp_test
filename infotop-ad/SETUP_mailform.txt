フォーム送信後の資料ダウンロード 概要と公開前チェック
=====================================================================

■ 仕組み
  LPのフォーム → 確認画面 → 送信 → 送信完了ページ(thanks.html)
  - フォーム処理:https://www.infotop.jp/html/contact/mail/mail_utf8.php(新規・UTF-8版)
    現行の mail.php(EUC-JP・製本配送/シェアアドレス/違反通報などと兼用)をもとに、
    このLP専用に作り直したもの。現行の mail.php は変更せずに残す。
  - mail_utf8.php に実装済みのもの
    ・確認画面(LPのデザイン/Cloudflare Turnstile の認証あり)
    ・管理者宛てメール(ad@first-penguin.co.jp)
    ・自動返信メール(資料5点+まとめてダウンロードのリンク入り)
    ・送信完了後に thanks.html へ移動
    ・現行と同じ防御(連続送信の制限/不正な画面遷移の防止/infotop.jp 以外からの送信拒否)
  - mail_utf8.php と設置手順(設置手順_mail_utf8.txt)は、ボット対策の秘密鍵を含むため
    このフォルダ(公開リポジトリ)には入れず、別途お渡ししています。
  - 資料は添付せず「リンク」でお届けする(容量制限・迷惑メール判定・悪用時の大量送信を避けるため)。

---------------------------------------------------------------------
1. 資料ファイルを用意して公開する
---------------------------------------------------------------------
  | 資料 | 公開URL |
  |---|---|
  | 媒体資料 | https://www.infotop.jp/html/advertishing/infotop-media.pdf(現行) |
  | DM広告資料 | https://info-penguin.com/advertising_media-kit/DM.pdf |
  | Facebook広告資料 | https://info-penguin.com/advertising_media-kit/Facebook.pdf |
  | リスティング広告資料 | https://info-penguin.com/advertising_media-kit/listing_ad.pdf |
  | 電話クロージング代行資料 | https://www.info-penguin.com/serviceguide/tel_closing.pdf |
  | まとめてダウンロード(ZIP・約110MB) | https://info-penguin.com/advertising_media-kit/all.zip |

  - 推奨:現行の媒体資料PDFは約75MBあるため、画像を圧縮して軽くする
    (目安 10MB以下)。スマホからのダウンロードが楽になる。
  - 各資料のURLは thanks.html・下記メール文面に反映済み。

---------------------------------------------------------------------
2. 送信完了ページ・自動返信メール
---------------------------------------------------------------------
  - mail_utf8.php に実装済み(送信完了後は LP の thanks.html へ移動、自動返信は資料リンク入り)。
  - 自動返信の文面を変える場合は、mail_utf8.php の $remail_text(本文)・$re_subject(件名)・
    $mailSignature(署名)を編集する。資料のURLを変える場合は thanks.html とあわせて直す。
  - 設置・テストの手順は「設置手順_mail_utf8.txt」を参照。

---------------------------------------------------------------------
4. 迷惑メール対策(届きやすくするために)
---------------------------------------------------------------------
  - 送信元ドメインに SPF・DKIM・DMARC を設定する(DNS管理者の作業)。
    Gmail・Yahoo!メールなどは、これがないと迷惑メール扱い・受信拒否になりやすい。
  - 本文はテキスト形式。URLは短縮URLを使わず、正式なURLをそのまま記載する。
  - 添付ファイルは付けない。
  - フォームにボット対策(reCAPTCHA など)を入れる。
    他人のメールアドレスを使った大量送信に悪用されると、送信元ドメインの評価が下がり、
    通常の業務メールも届きにくくなるため。

---------------------------------------------------------------------
5. 公開前のテスト
---------------------------------------------------------------------
  - Gmail / Outlook / 携帯キャリアメールなど複数のアドレスで送信テストし、
    自動返信が「受信トレイ」に届くか、リンクから資料をダウンロードできるかを確認する。
  - 送信後に thanks.html が表示され、5つの資料とまとめてダウンロード(ZIP)のボタンからダウンロードできるかを確認する。
