インフォトップ 広告掲載LP(リニューアル版) README
====================================================

■ 公開前に差し替え・確認が必要な箇所(必ず確認)
  1. 仮テキストの [ ] 部分(index.html 内を「[」で検索)
     - [○]営業日以内 …… 「相談の流れ STEP02」「お問い合わせ見出し下」
     - [最低出稿金額] / [○]営業日 / [回答を確認中] …… よくある質問
     - [平日 10:00~18:00] …… お電話でのご相談の受付時間
  2. 「相談の流れ」「よくある質問」は仮テキストです。正式な文言に差し替えてください。
  3. 「※数値の算出条件・時点を注記」…… 数字セクション下の注記を正式な文言に。
  4. フォームの送信先(後述「フォーム」を参照)。
  5. canonical / og:url / og:image は GitHub Pages の確認用URLになっています。
     本番公開時は本番URLに書き換えてください(index.html の <head> 内)。

■ フォルダ構成
  index.html        …… ページ本体
  css/style.css     …… スタイル(セクションごとに見出しコメントで区切り)
  js/main.js        …… タップ時の押し下げ対応(iOS)/ PCの追従ボタン表示制御
  images/           …… 画像(ファイル名は画像台帳と同じ)
  README.txt        …… このファイル
  CREDITS.txt       …… 画像の出典

■ ボタンの押し下げアニメーション
  - PC:マウスオーバーで押し下げ(style.css「@media (hover: hover)」内)
  - SP:タップ時に押し下げ(:active。iOS向けに js/main.js に touchstart の空リスナー)
  - 対象クラス:.btn(.btn--primary / --white / --yellow / --navy / --outline)

■ フォーム(埋め込み用)
  - index.html の「▼▼▼ フォーム埋め込みブロック ここから」~「▲▲▲ ここまで」を
    div.lp-form ごとコピーすれば、他のページにも埋め込めます。
    必要なCSSは style.css の「lp-form」部分(.lp-form〜.lp-form__note)です。
  - 送信先(action):https://www.infotop.jp/html/contact/mail/mail.php
    現行ページ(ad_application)のフォームと同じ送信先・同じ項目名(name属性)にしています。
      お問い合わせ(hidden)/ 貴社名 / お名前 / E-Mail / 連絡先電話番号 /
      掲載したいカテゴリー / ご予算 / 自由記入欄 / 同意事項[] / 入力必須[](hidden)
  - 現行フォームは Mailform Pro(確認画面・自動返信など)で動いています。
    本番では、現行ページで読み込んでいる Mailform Pro のスクリプト
    (mfp.statics など)を同じように読み込み、送信テストを行ってください。
    GitHub Pages など別ドメインからの送信は、送信先側の設定によって拒否されることがあります。
  - カテゴリーに「その他」を追加しています。
  - 入力必須は「お名前・メールアドレス・電話番号・同意」です(HTMLの required 属性)。

■ 画像の差し替え
  - images/ の同じファイル名で、同じ縦横比の画像を上書きすれば差し替わります。
      hero_staff.png   ヒーローの女性(透過PNG・約1:1)
      problem_01~03.jpg  お悩みの写真(760×520)
      before.png / after.png  相談前後のイラスト(透過PNG・縦長)
      strength_01~03.png  強みのイラスト(1040×600)
      menu_mailmag.png メルマガ配信のイラスト(640×360)
      cta_staff.png    CTAの女性(透過PNG)
      voice_01~05.png  お客様の声のアイコン(正方形)
      media_cover.jpg  媒体資料の表紙
      logo.png         ロゴ(背景透過)
      ogp.jpg          SNSシェア用画像(1200×630)
  - 画像を差し替えたら、<img> の alt(画像の説明文)も内容に合わせて書き換えてください。

■ お客様の声の追加・削除
  - <article class="voice-card"> ~ </article> が1件分です。コピーして増やす/削除します。
  - 「続きを読む」は details 要素で開閉します(JS不要)。全文は <p> 内に記入。
  - PCは段違い配置(style.css「voice-card:nth-child」)。件数を変えた場合は配置を調整してください。

■ よくある質問の追加・削除
  - <details class="faq-item"> ~ </details> が1問分です。最初から開いておく場合は open を付けます。

■ 広告メニューの追加・削除
  - <li class="menu-card"> ~ </li> が1件分です。
    「メルマガ配信」は大きいカード(menu-card--main)、最後の黄色の帯は相談への誘導です。

■ ページ内リンク
  - ボタンの #contact(フォーム)/ #media(媒体資料)へスムーズにスクロールします。
  - OSで「視差効果を減らす」を設定している場合はアニメーションを無効にします。

■ ここまでの決定事項(要約)
  - 現行LP(画像中心)をテキスト中心の構造化HTMLに作り直し。実績は「20年」に更新。
  - 構成:ヒーロー → 01お悩み → 02解決 → CTA → 03強み → 04メニュー → 05数字
          → 06お客様の声 → CTA → 07相談の流れ → 08FAQ → 09お問い合わせ(フォーム+媒体資料)
  - デザイン:シフトラ(aishift.com)を参考に、角丸の大パネルと誌面風の番号見出しの折衷案。
    セクションごとに背景色を切り替え、境目をはっきりさせる。配色は青・紺・黄。
  - ヘッダーはロゴのみ、フッターはコピーライトのみ。LINEボタンは削除。
  - 画像:ヒーロー・相談前後・CTAはイラスト(同じテイスト)、お悩みは実写、
    強みは人物なしのイラスト(デフォルメした動物)。
  - TDK(title / description / keywords)を設定。全画像に alt を設定。
