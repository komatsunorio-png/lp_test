スポーツ特集 LP(infotop) 運用README
====================================

■ 公開前に差し替え・確認すること
  1. 商品リンク(詳細を見る)が全て仮の「#」です。index.html 内の
     <a class="btn" href="#">詳細を見る</a> の href を各商品のURLに変更してください。
  2. バナー(お悩みレスキュー)とヘッダーのロゴのリンクも「#」です。
     <a class="banner__link" href="#"> / <a class="fv__logo" href="#"> を変更してください。
  3. 仮画像は残っていません(全て最終画像)。
  4. 商品「上達志向ゴルファー待望の短期集中本格プログラム！」の説明文中
     「3慢人」は元ページの表記のままです。誤記(「3万人」等)でないか原稿元で確認してください。
  5. ゴルフ2のサムネイル(thumb_golf_02.jpg)にAI生成の小さな「14」の看板が写っています。気になる場合は差し替えてください。
  6. フォント(Noto Sans JP / Anton / Oswald)は Google Fonts から読み込みます。

■ フォルダ構成
  index.html        ページ本体
  css/style.css     スタイル(役割ごとにセクション分け)
  js/main.js        iOSのタップ時押し下げ用の空リスナー
  images/           画像(ファイル名は台帳どおり)
  README.txt / CREDITS.txt

■ 商品の追加・削除・並べ替え
  各商品は index.html の中で
    <!-- ▼▼▼ 商品 N ここから -->  ～  <!-- ▲▲▲ 商品 N ここまで -->
  で囲まれた <li class="card"> 1個です。
  - 追加: 同じジャンルの <ul class="cards"> 内に、既存の商品ブロックを丸ごとコピーして貼り、中身を書き換える。
  - 削除: ▼▼▼～▲▲▲ の範囲をまるごと消す。
  - 並べ替え: 範囲ごと切り取って、別の位置へ貼る。
  商品が奇数のとき最後の1件は中央に配置されます。
  (商品番号のコメントは目印です。ずれても表示には影響しません)

■ ジャンルの追加
  「ジャンルブロック ここから～ここまで」の範囲(<section class="genre genre--◯◯" id="◯◯">)をコピーし、
  id・見出し・英字・番号を変更。色は css/style.css の
  「.genre--baseball」等の行をコピーして --c(基本色) --dark(見出し色) --bg(背景) --ghost(英字の薄色)を設定。
  ヒーロー内の <nav class="genre-nav"> にも <li> を1つ追加し(.gbtn--◯◯ の色をCSSに追加)、
  ボタンの列数は style.css の .genre-nav ul の grid-template-columns を変更してください。

■ 「上達」リボンの削除
  <span class="card__ribbon">上達</span> の行を削除します(全商品から消すときは、CSSの .card__ribbon を display:none に)。

■ サムネイル・画像の差し替え
  同名で images/ 内のファイルを上書きするのが簡単です(サムネは16:9、960×540px推奨)。
  別名にする場合は <img src="images/…"> と alt も変更してください。
  FVの人物は透過PNG(fv_person*.png)。位置・大きさは style.css の .person--◯◯ の
  --l(左) --h(高さ) --b(下) と z-index で調整できます(数値はPC1440px/SP390pxを基準にした値)。

■ リンク先URLを入れる場所
  商品: 各商品の <a class="btn" href="#">。 バナー: <a class="banner__link" href="#">。

■ 実装メモ
  - レスポンシブ: 900px以下はSP表示(390px基準で拡縮、最大560px)。PCは1440px基準(--u)で拡縮。
  - ボタン: PCはマウスオーバーで押し下げ、SPはタップ(:active)で押し下げ。
  - ジャンルボタンはページ内スムーズスクロール(「視差効果を減らす」設定では無効)。
  - ヒーロー説明文: PCはネイビー帯内(波形の背面に隠れないよう)に白文字で配置しています。

■ これまでの指示・決定事項(要約)
  - 対象: infotop「スポーツ特集」のリニューアル。商品は元ページと同一内容。
  - ロゴ(o内部を透過したPNG)とお悩みバナーは支給画像。バナーはPC/SP共用。
  - サムネイルと人物は生成AIで作成(商品画像は使わない)。
  - 商品カードに赤い「詳細を見る」CTAを設置。ロゴはヒーローになじませる。
  - フッターはコピーライトのみ(お悩み特集バナーを上に配置)。
  - ヒーローは巨大英字・人物の重なり・ブラシ状の帯・ジャンルボタン一体型のデザイン。
