語学特集 | インフォトップ  リニューアル版
================================================

■ 公開前に確認・差し替えが必要なもの
  1. ジャンル紹介文(英語 / アジアの言語 / 手話)は仮文言です。
     index.html 内の「<!-- 仮文言:公開前に要確認 -->」の直後の <p> を確定文に差し替えてください。
  2. ロゴ(images/logo.png)は、いただいた画像(263×92px)から白背景を透明にしたものです。
     高解像度のPNGまたはSVGがあれば、同じファイル名で上書きしてください。
  3. 商品リンクは旧ページと同じアフィリエイトURL(aid=225890)を入れています。変更がある場合は差し替えてください。


■ フォルダ構成
  index.html            ページ本体
  css/style.css         スタイル(役割ごとに 1〜11 のセクションに分けています)
  js/main.js            タップ時の押し下げ(iOS)用の最小限のスクリプト
  images/               画像(ファイル名は画像台帳と同じ)
  README.txt            このファイル
  CREDITS.txt           画像の出典


■ 商品を追加する
  1. index.html で、追加したいジャンルの
     「<!-- ▼▼▼ 商品 N ここから -->」〜「<!-- ▲▲▲ 商品 N ここまで -->」を1件分コピーします。
  2. 同じ <ul class="product-list ..."> の中に貼り付けます(並べたい位置に)。
  3. 次の5か所を書き換えます。並びは「サムネ → 商品名 → 販売者 → 価格 → 説明文 → ボタン」で固定です。
       - サムネ   : <img src="images/○○.jpg" alt="画像の内容">
       - 商品名   : <h3 class="product__name"><a href="リンク先">商品名</a></h3>
       - 販売者   : <p class="product__seller">販売者:○○</p>
       - 価格     : <p class="product__price">¥○○</p>
       - 説明文   : <p class="product__desc">○○</p>
       - ボタン   : <a class="btn" href="リンク先">  ※商品名と同じURL
  4. コメントの番号(商品 N)は通し番号に振り直してください(表示には影響しません)。

  ※ 英語ジャンルはPCで2列・右列を少し下げた互い違いの配置になります。4件以上になると、右下の小物(本とティーセット)は自動で非表示になります。
  ※ アジアの言語・手話は「見出し+商品」の左右配置です。商品を増やすと、右(手話は左)の列に縦に並びます。


■ 商品を削除する
  削除したい商品の「▼▼▼ 商品 N ここから」〜「▲▲▲ 商品 N ここまで」を、コメントごと削除します。
  一時的に隠すだけなら、範囲全体を <!-- と --> で囲んでコメントアウトしてください。
  (アジアの言語の「商品 5:3分ドラマで覚える!!らくらく韓国語」は、旧ページで非表示だったため、コメントアウトした状態で残しています。
    表示する場合はコメントを外し、サムネ images/thumb_asia02.jpg を用意してください。)


■ 商品を並べ替える
  「▼▼▼ ここから」〜「▲▲▲ ここまで」の範囲ごと、切り取って貼り付け直します。
  サムネの角の丸め方(大きく丸める角)は並び順で自動的に変わります。


■ ジャンルを追加する
  1. 「ジャンル:○○ ここから」〜「ジャンル:○○ ここまで」のブロックを丸ごとコピーします。
     - 商品が多いジャンル → 英語ブロック(genre--english の形)
     - 商品が1〜2件のジャンル → アジアの言語ブロック(genre--split の形。左右を反転したい場合は genre--reverse を追加)
  2. section の id、h2 の id と aria-labelledby、英字見出し(genre__en)、日本語ラベル(genre__label)、紹介文を書き換えます。
  3. 背景色などは css/style.css の「6. ジャンル」に、既存の .genre--english などを参考に
       .genre--新しい名前 { --bg: 背景色; --en: 英字見出しの色; --label: ラベルの色; --card-shadow: カードの影色; }
     を追加し、section の class に genre--新しい名前 を付けます。
  4. 境目の小物(genre__deco)が不要な場合は、その <img> を削除してください。


■ リボンを付ける/外す
  現在、商品カードに「上達」リボンは付けていません(カンプ確認時に削除済み)。


■ 画像を差し替える
  images/ 内の同じファイル名で上書きすれば差し替わります。縦横比は元の画像と同じにしてください。
    - サムネ(thumb_*.jpg)        : 16:9(1120×630px 推奨)
    - 人物(fv_person.png)        : 背景透過PNG。SPでは上部(頭〜腰)だけを表示します
    - 小物(obj_*, deco_*, fv_book) : 背景透過PNG
    - バナー(bnr_health_problems.gif): 600×120px


■ リンク先URLを入れる場所
  各商品の2か所(商品名の <a href> と「詳しく見る」ボタンの <a href>)に同じURLを入れてください。
  関連特集バナーのリンク先は <aside class="related"> 内の <a href> です。


■ 動き・レスポンシブ
  - 「詳しく見る」ボタンとバナーは、PCはマウスオーバー、スマホはタップ時に押し下がります。
  - 幅900px以上はPCレイアウト(1440px基準で縮小)、900px未満はSPレイアウト(390px基準)です。
  - 「動きを減らす」設定の端末では、アニメーションとスムーズスクロールを止めます。

  - 関連特集バナーは「お悩みレスキュー」画像
  - 「上達」リボンはなし
