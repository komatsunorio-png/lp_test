スポーツ特集（infotop）リニューアル README
==========================================================

■ 公開前に差し替え・確認が必要なもの
----------------------------------------------------------
1. 【仮画像（差し替え必須）】ジャンルアイコン 4点
   images/icon_baseball.svg / icon_soccer.svg / icon_golf.svg / icon_badminton.svg
   → 同じファイル名で上書きすれば差し替わります（白線のアイコン。色の丸はCSSで描画）。
     PNGにする場合は index.html の「ジャンル別ボタン」内の src の拡張子も変更してください。
2. 説明文の表記：ゴルフ1件目「アマチュアから賞金王まで3万人の〜」
   現行ページでは「3慢人」と表記されていたため、誤字と判断して「3万人」にしています。
3. Webフォント（Google Fonts：Dela Gothic One / Anton / Noto Sans JP）を読み込んでいます。
   社内の規定で外部フォントが使えない場合はご相談ください。

※商品リンクは現行ページと同じクリック計測URL（click.php?aid=225890&iid=商品ID&pfg=1）を設定済みです。
※商品画像・関連バナーは現行ページと同じく infotop.jp の画像URLを直接参照しています。


■ フォルダ構成
----------------------------------------------------------
index.html        ページ本体
css/style.css     スタイル（役割ごとにセクション分け）
js/main.js        商品のフェードイン、TOPボタン、iOSのタップ対応
images/           FV・ジャンル用の写真、ロゴ、ジャンルアイコン
README.txt        この説明
CREDITS.txt       画像の出典


■ 商品の追加・削除・並べ替え
----------------------------------------------------------
商品は index.html の中で、1件ずつ次のコメントで囲まれています。

  <!-- ▼▼▼ 商品 N ここから -->
  <li class="items__item"> … </li>
  <!-- ▲▲▲ ここまで -->

● 追加：同じジャンル内の「▼▼▼ ここから」〜「▲▲▲ ここまで」を丸ごとコピーして、
  追加したい位置に貼り付け、次の箇所を書き換えます。
   - サムネイル画像 …… <img src="https://www.infotop.jp/img/hp_商品ID.gif" alt="商品名">
   - キャッチコピー …… <h3 class="card__catch"><a href="リンク先">キャッチコピー</a></h3>
   - 販売者 ………………… <p class="card__seller">販売者：〇〇</p>
   - 価格 …………………… <data value="16500">16,500</data>（value はカンマなしの数字）
   - 説明文 ………………… <p class="card__desc">〇〇</p>
   - リンク先（2か所） … キャッチコピーの a と「商品ページを見る」ボタンの a の href
     例：http://www.infotop.jp/click.php?aid=225890&amp;iid=商品ID&amp;pfg=1
     （HTML内では & を &amp; と書きます）
● 削除：「▼▼▼ ここから」〜「▲▲▲ ここまで」を丸ごと削除します。
● 並べ替え：ブロック単位で切り取り・貼り付けします。
※コメント中の番号（商品 N）は目印です。ずれても表示には影響しません。

● レイアウトは件数に合わせて自動で変わります。手作業の調整は不要です。
   - PC・タブレット：2列で、偶数番目のカードが少し下がった段違いの配置
   - SP：1列で、カードを左右交互に少しずらして配置
   - 1件だけのジャンル：自動で横長の大型カードになる
   - フェードイン：追加した商品にも自動で適用されます

● 構造化データ（検索エンジン向け）
  index.html の <head> 内 <script type="application/ld+json"> に商品一覧があります。
  商品を追加・削除・変更したら、ここの itemListElement も同じ内容に合わせてください
  （position は上から 1, 2, 3 … の連番）。


■ 「上達」リボンの削除
----------------------------------------------------------
各商品の <span class="card__ribbon">上達</span> の1行を削除します。
文言の変更は「上達」の部分を書き換えます。


■ ジャンルの追加
----------------------------------------------------------
1. 「<!-- ===== ジャンル：〇〇 ここから ===== -->」〜「ここまで」を丸ごとコピーして貼り付け。
2. section の id（例：id="tennis"）、aria-labelledby、h2 の id を新しい名前にそろえる。
3. section の style でジャンルの色を指定：--c（濃い色）と --c2（背景の薄い色）。
4. ジャンル写真 images/genre_〇〇.png、英字（genre__en・genre__title-en）、日本語名を書き換え。
5. 「ジャンル別ボタン」の <ul> に <li> を1つ追加（href="#新しいid"、style="--c: 色"、アイコン画像）。
※写真の左右・背景帯の向きは、並び順で自動的に入れ替わります。


■ 画像の差し替え
----------------------------------------------------------
images/ 内の同名ファイルを、同じ縦横比の画像で上書きしてください。
- fv_bg_pc.jpg / fv_bg_sp.jpg …… FV背景（PC／SP・タブレット）
- fv_person_*.png ………………… FVの人物（透過PNG）
- genre_*.png ……………………… ジャンルの人物（透過PNG）
- logo.png ………………………… ロゴ（背景透過済み）
- icon_*.svg ……………………… ジャンルアイコン【仮】


■ 表示の仕様
----------------------------------------------------------
- ブレークポイント：SP 〜599px ／ タブレット 600〜1023px ／ PC 1024px〜
- FVは画面幅に合わせて全体を拡大縮小（PC：1440px基準、SP・タブレット：390px基準・最大560px）
- ボタンの押し下げ：PCはマウスオーバー、SPはタップで反応
- ジャンル別ボタン・TOPボタン：スムーススクロール（「視差効果を減らす」設定の端末では無効）
- 商品カードは、画面に入ったときにフェードイン（「視差効果を減らす」設定の端末では最初から表示）
- TOPボタン：ジャンル別ボタンより下までスクロールすると、画面右下に表示


■ これまでの指示・決定事項
----------------------------------------------------------
- 現行ページの、グリッドに沿わないダイナミックなデザインを踏襲する。
- 商品数が少なくても見劣りせず、増減しても崩れない構造にする
  （全ジャンル共通のテンプレート＋商品カード1種類。段違い・1件時の大型表示はCSSで自動）。
- ジャンル別ボタンには商品数を表示しない（更新漏れの防止）。
- 追従ナビはTOPボタンのみ。
- ヘッダーはロゴのみ、フッターはコピーライトのみ。
- 商品カードの並び：サムネ → キャッチコピー → 販売者 → 価格 → 説明文 → 商品ページボタン（赤）。
- SPのジャンル見出しは高さを抑え、人物写真の下半分を商品カードの背後に隠す。
- レスポンシブ／構造化（セマンティックHTML＋JSON-LD）／商品一覧はフェードイン程度のスクロールアニメーション。
- FV・ジャンルの人物はAI生成（日本人・白背景の全身写真を切り抜き）。
